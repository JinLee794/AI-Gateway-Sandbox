    One product per plan: AI models, MCP tools and A2A agents under one contract

    Each plan is an API Management product that bundles the AI model API, the MCP server and the A2A agent API. A single product policy enforces the plan: which models, tools and agents a subscriber may use, rate and token limits, and one $ budget shared across all three. Agents subscribe to a plan, and the gateway prices every call from the price list below.

    Agent-to-agent chargeback

    When an agent calls the Sourcing Agent, the agent's own model and tool calls go back through the gateway with its platform identity. The gateway tags them on behalf of the caller, so the caller pays the per-task fee plus everything the agent consumed.
