Each card is one subscription key, and the gateway bills whoever's key makes the call. So pick an app or a user: a call is never both.
A user working through an agent? Pick the user, then the A2A agent tab. The agent makes model and tool calls on the user's behalf, and the gateway bills the user (x-gw-on-behalf-of). Only the agent platform may name someone else to bill, so an ordinary app can't push its cost onto a user.
